# PSYC 210 Item Analysis

Quarto website of item analyses for PSYC 210 exams.

## Data

Raw response data is excluded from this repository for privacy.
To reproduce, place exam files in `data/` following the naming pattern
`{semester}-exam-{NN}.csv`, then run `quarto render`.

Rendered reports in `docs/` contain only aggregated, de-identified output.
